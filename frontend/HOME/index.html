What we track

Three categories. One crowded neighborhood.

Every tracked object falls into one of three groups — each behaving, and mattering, differently.

Satellites

Active spacecraft currently in orbit — from communications constellations to scientific platforms.

Space Debris

Inactive spacecraft, fragments and remnants left behind — the largest and least predictable share of the environment.

Close Approaches

Objects predicted to pass within a defined proximity threshold — screened continuously, not just observed after the fact.

How it works

From raw tracking data to a picture you can read.

Real orbital data

Ingest

Publicly available tracking data is pulled in continuously from orbital data sources.

Data processing

Validate & normalize

Records are cleaned, deduplicated and standardized into a consistent object model.

Orbit propagation

Compute positions

Each object's trajectory is propagated forward in time to estimate where it will be.

Proximity analysis

Screen for close approaches

Propagated paths are compared to flag objects predicted to pass near one another.

Visualization

Render the result

The processed environment is rendered back as a live, explorable 3D view.

This project is a web-based dashboard designed to track space debris and active satellites in Low Earth Orbit using public TLE data from CelesTrak. As orbital congestion increases, collision risks threaten vital space infrastructure. Our tool leverages the SGP4 propagation algorithm to predict orbital paths and detect close-approach conjunction events in near real-time. Key features include an interactive 3D visualization of Earth, where users can view satellite trajectories and pinpoint predicted collision zones. By highlighting high-risk events with an intuitive risk score, this accessible platform democratizes space traffic management for students, researchers, and small-scale satellite operators.
